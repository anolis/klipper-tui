Engineered for Performance

Everything you need. Zero bloat.

klipper-tui talks directly to Moonraker over persistent async WebSockets with sub-millisecond dispatch.

Isometric 3D Wireframe Projection

Render your entire 3D build volume directly in terminal character cells with real-time toolhead coordinates, auto-spin, and dynamic axis bounds.

Sub-Cell Braille Temperature Graphs

Four times the vertical resolution of regular ASCII charts. High-density UTF-8 braille matrix with target temperature line overlays.

Color-Coded Bed Mesh Heightmaps

Instant visual feedback on your bed level variance. Live probe tracking during calibration and profile persistence.

Interactive G-Code Shell with History

Send raw G-code, Klipper macros, and Moonraker RPC requests with arrow-key history recall (↑/↓) and formatted responses.

Live Terminal Webcam Streaming

Stream your print bed camera directly in your terminal via optional textual-image half-block rendering or ASCII mode.

Multi-Theme Token Architecture

Fully semantic theming system with built-in dark palettes: Ominous, Mainsail, and Forge. Cycle themes instantly with t.

Get Started in Seconds

Install & Run

Requires Python 3.10 or newer. Works on Linux and macOS.

1

Install via pipx

Install in an isolated environment with a global executable:

pipx install klipper-tui
2

Launch with Hostname

Point klipper-tui to your printer's Moonraker IP or mDNS address:

klipper-tui mainsailos.local
3

Or Set Env Variable

Save your default printer host in your shell config (~/.bashrc / ~/.zshrc):

export KLIPPER_HOST=192.168.1.50
klipper-tui
